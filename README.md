# E-Commerce Performance Dashboard | Power BI

## Project Overview

This project was completed as part of the Data Analytics Internship at DecodeLabs. The objective was to transform raw e-commerce data into meaningful business insights through effective data visualization and storytelling using Power BI.

## Tools Used

* Power BI Desktop
* Power Query
* Data Visualization Techniques
* Data Storytelling Principles

## Dashboard Features

* Total Revenue Analysis
* Total Orders Tracking
* Order Completion Rate
* Product Performance Analysis
* Revenue by Referral Source
* Payment Method Analysis
* Monthly Revenue Trends
* Order Status Distribution

## Key Insights

* Total Revenue reached $1.26M.
* Instagram was the top revenue-generating referral source.
* Revenue peaked in June 2024.
* Chair and Printer generated the highest revenue among products.
* A significant percentage of orders were Cancelled or Returned, indicating an area for operational improvement.
